## WORKFLOW（固定执行顺序，不可跳过）

### STEP 1 · 设计图解析 [ANALYZE]
输出一份结构化分析报告，包含以下五项：

**A. 布局骨架**
- 整体分几个区域（Header / Body / Footer）
- Body 列数、是否有嵌套、网格还是 Flex
- 是否包含交互组件（Tabs / Accordion / Slider / Modal）

**B. Block 识别**
- 哪些是可重复单元 → 用 block 管理，列出字段清单
- 哪些是全局配置 → 用 section settings 管理

**C. 视觉规格**
- 色值（背景 / 文字 / 强调 / 边框）
- 字号字重层级（H1/H2/Body/Caption 各是多少）
- 间距（Gap / Padding / Margin 估算值）
- 圆角 / 阴影 / 边框
- 特殊效果（渐变 / 毛玻璃 / hover 动效 / 遮罩）

**D. 响应式策略**
- 桌面（≥1280px）：设计图 1:1 还原
- 平板（768–1279px）：列数调整方案
- 手机（<768px）：单列排布，内容优先级

**E. 文件命名**
- 根据功能语义命名，如：
  `feature-cards` / `testimonial-slider` / `product-comparison` / `hero-banner`
- 输出：`sections/[name].liquid` 和 `assets/section-[name].css`

分析完成后直接进入 STEP 2，无需等待确认。

### STEP 2 · Liquid 文件生成 [BUILD-LIQUID]

严格按以下模板结构输出，不得改变顺序：

```liquid
{{ 'section-[name].css' | asset_url | stylesheet_tag }}

<div class="[name] section-{{ section.id }}-padding color-{{ section.settings.color_scheme }} gradient"
  style="--section-max-width: {{ section.settings.max_width }}px;">
  <div class="[name]__inner page-width">

    <!-- Section Header（如有标题） -->
    {%- if section.settings.heading != blank -%}
      <div class="[name]__header">
        <{{ section.settings.heading_size }} class="[name]__heading">
          {{ section.settings.heading | escape }}
        </{{ section.settings.heading_size }}>
        {%- if section.settings.subheading != blank -%}
          <p class="[name]__subheading">{{ section.settings.subheading | escape }}</p>
        {%- endif -%}
      </div>
    {%- endif -%}

    <!-- Blocks -->
    {%- if section.blocks.size > 0 -%}
      <div class="[name]__grid">
        {%- for block in section.blocks -%}
          <!-- 根据设计图渲染每个 block -->
        {%- endfor -%}
      </div>
    {%- endif -%}

  </div>
</div>

{%- style -%}
  .section-{{ section.id }}-padding {
    padding-top: {{ section.settings.padding_top | times: 0.75 | round: 0 }}px;
    padding-bottom: {{ section.settings.padding_bottom | times: 0.75 | round: 0 }}px;
  }
  @media screen and (min-width: 750px) {
    .section-{{ section.id }}-padding {
      padding-top: {{ section.settings.padding_top }}px;
      padding-bottom: {{ section.settings.padding_bottom }}px;
    }
  }
{%- endstyle -%}

{% schema %}
{
  "name": "...",
  "tag": "section",
  "class": "section",
  "disabled_on": { "groups": ["header", "footer"] },
  "settings": [ ... ],
  "blocks": [ ... ],
  "presets": [ { "name": "...", "blocks": [...] } ]
}
{% endschema %}
```

**Liquid 强制规则（每条都必须遵守）：**

| # | 规则 |
|---|---|
| L1 | CSS 只通过 `asset_url + stylesheet_tag` 引入，样式不写进 liquid，动态 padding 除外（用 `{%- style -%}` 块）|
| L2 | 无硬编码文字、颜色、链接，全部通过 settings / block settings 控制 |
| L3 | 可重复内容全部用 `section.blocks` 管理，用 `{% for block in section.blocks %}` 渲染 |
| L4 | 图片必须用响应式写法（见下方 IMAGE 模板） |
| L5 | 链接用 `<a>`，JS 交互用 `<button>`，aria-label 不可省略 |
| L6 | Schema 必须包含 `color_scheme` / `padding_top` / `padding_bottom` / `max_width` |
| L7 | Block 数量用 `"limit"` 控制（卡片类默认 12）|
| L8 | 每个 block 元素必须加 `{{ block.shopify_attributes }}` 支持编辑器高亮 |
| L9 | 空内容用 `{%- if ... != blank -%}` 判断，不渲染空标签 |
| L10 | `{% schema %}` 中每个 settings 项必须有 `"default"` 值 |

**IMAGE 标准模板（每次图片渲染都用这个）：**
```liquid
{%- if block.settings.image != blank -%}
  {{
    block.settings.image
    | image_url: width: 800
    | image_tag:
      loading: 'lazy',
      widths: '375, 550, 750, 800',
      width: block.settings.image.width,
      height: block.settings.image.height,
      class: '[name]__img',
      alt: block.settings.image.alt | escape
  }}
{%- else -%}
  {{ 'image' | placeholder_svg_tag: '[name]__img placeholder' }}
{%- endif -%}
```

**SCHEMA 标准 Settings 块（每个 Section 必须包含，放在 settings 数组末尾）：**
```json
{ "type": "header", "content": "样式" },
{
  "type": "color_scheme",
  "id": "color_scheme",
  "label": "配色方案",
  "default": "scheme-1"
},
{
  "type": "range",
  "id": "max_width",
  "label": "内容最大宽度",
  "min": 800, "max": 1600, "step": 40, "unit": "px",
  "default": 1200
},
{ "type": "header", "content": "间距" },
{
  "type": "range",
  "id": "padding_top",
  "min": 0, "max": 120, "step": 4, "unit": "px",
  "label": "上内边距",
  "default": 60
},
{
  "type": "range",
  "id": "padding_bottom",
  "min": 0, "max": 120, "step": 4, "unit": "px",
  "label": "下内边距",
  "default": 60
}
```

### STEP 3 · CSS 文件生成 [BUILD-CSS]

**CSS 文件结构（固定分区注释）：**
```css
/* ============================================================
   section-[name].css
   ============================================================ */

/* ── 1. CSS 变量 ─────────────────────────────────────────── */
/* ── 2. 容器 / 布局 ──────────────────────────────────────── */
/* ── 3. Section Header ───────────────────────────────────── */
/* ── 4. 卡片 / Block 单元 ────────────────────────────────── */
/* ── 5. 图片 ─────────────────────────────────────────────── */
/* ── 6. 文字排版 ─────────────────────────────────────────── */
/* ── 7. 按钮 ─────────────────────────────────────────────── */
/* ── 8. 特效（hover / 动画 / 渐变）─────────────────────── */
/* ── 9. 响应式 ───────────────────────────────────────────── */
```

**CSS 强制规则（每条都必须遵守）：**

| # | 规则 |
|---|---|
| C1 | 颜色优先使用 Dawn 变量：`rgb(var(--color-foreground))` / `rgb(var(--color-background))` / `rgb(var(--color-button))`；品牌色直接写 `#0067FF` |
| C2 | 字体不重复声明，继承 Dawn 全局 |
| C3 | 图片容器用 `aspect-ratio` 控制比例，不用固定 `height` |
| C4 | 动画只用 `transform` 和 `opacity`，不用 `width` / `height` / `margin` 做动效 |
| C5 | hover 效果必须包在 `@media (hover: hover)` 里，防止移动端误触 |
| C6 | `transition` 写完整三段：`property duration easing`，禁用 `transition: all` |
| C7 | 断点统一：手机 `max-width: 767px` / 平板 `min-width: 768px` and `max-width: 1023px` / 桌面 `min-width: 1024px` |
| C8 | 字号用 `rem`（Dawn 基准：`1.4rem = 14px` / `1.6rem = 16px` / `2rem = 20px`）|
| C9 | Grid 列数用 CSS 变量控制，方便响应式覆盖：`grid-template-columns: repeat(var(--columns, 3), 1fr)` |
| C10 | 不写 `!important`，通过选择器权重控制优先级 |

**断点模板（每次响应式都用这个结构）：**
```css
/* 桌面（默认，≥1024px）*/
.xxx { --columns: 3; }

/* 平板 */
@media screen and (min-width: 768px) and (max-width: 1023px) {
  .xxx { --columns: 2; }
}

/* 手机 */
@media screen and (max-width: 767px) {
  .xxx { --columns: 1; }
}
```
